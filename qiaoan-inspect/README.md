# 桥安探视 · GitHub Pages 版

照片上传、暗线初筛、手动标注、复核入库、报告导出与桥梁养护管理。

## 发布到 GitHub Pages

1. 在自己的 GitHub 账号下创建名为 `qiaoan-inspect` 的仓库。免费账号使用公开仓库。
2. 将本目录里的文件上传到仓库根目录，确保 `index.html` 直接位于根目录，不要再套一层文件夹；不要把 ZIP 文件本身上传作为网站。
3. 打开仓库 **Settings → Pages**。
4. 在 **Build and deployment → Source** 选择 **Deploy from a branch**。
5. 选择 **main** 分支和 **/(root)**，保存。
6. 等待 Pages 发布完成，使用 **Visit site** 显示的实际地址访问。

项目网址的格式为 `https://你的用户名.github.io/qiaoan-inspect/`。这是格式说明，尚不是已发布网址。

无需 npm、构建步骤、数据库或密钥。包含 `.nojekyll`，禁用不需要的 Jekyll 处理。样式、脚本使用相对路径，可部署到项目子目录。

GitHub Pages 是静态托管，不执行 Python。照片初筛在访客自己的浏览器中计算，无须调用外部模型 API。网络通达情况取决于所在地网络，发布成功不等于所有网络都可稳定访问。

## 使用

1. 点击“上传构件照片”，选择 JPG、PNG 或 WebP（单张 ≤ 20 MB，队列最多 12 张）。
2. 点击“开始分析”，系统根据真实像素提取暗线候选区域。
3. 逐项选择病害类型和复核状态，或使用“手动框选”补充。
4. 填写桥梁、构件和复核说明，点击“保存记录 / 更新病害台账”。
5. 导出图文报告、标注图片或 JSON 备份。“检测记录”支持恢复与导入备份。

如果使用尺度标定，参考物和目标需处于同一平面、近似正视；框范围不是裂缝宽度。

## 本地运行与未来模型接入

在本目录运行 `python3 server.py`（Windows 可用 `py server.py`），打开 http://127.0.0.1:8080 。

专业模型需配置环境变量 QIAOAN_MODEL_URL、可选 QIAOAN_MODEL_TOKEN。密钥只保存在服务器环境变量中。协议参见“模型接口说明.md”。

## 数据与迁移

照片和检测记录保存在浏览器 IndexedDB，任务、病害台账和工单保存在 localStorage。照片不会随 GitHub 仓库发布，也不会由本地初筛发送到服务器。更换网址或浏览器后存储不共享；请在旧网址先导出 JSON，在新网址“检测记录”导入。

仓库仅含应用源码、通用说明与内置演示数据；不包含用户上传照片、运行时数据库、API 密钥和原始项目文档。

## 能力边界

当前是传统图像初筛，并非已训练的 D-FINE / SAM。接缝、阴影、文字可能被误检；细微裂缝可能漏检。候选必须人工复核，不构成结构安全诊断。

专业模型、多人同步、视频跟踪、点云融合和设备控制需要额外后端及模型资源。
