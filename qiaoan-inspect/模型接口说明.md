# 桥安探视模型接入协议

当前网站可用的是浏览器本地图像初筛。以下接口用于未来接入专业模型，不包含模型权重。

## 启动

安装 Python 3 后，在 qiaoan-site 目录运行 `python3 server.py`，打开 http://127.0.0.1:8080 。Windows 可使用 `py server.py`。

模型服务部署完成后，在启动服务的进程环境中配置：

- QIAOAN_MODEL_URL：固定模型推理地址，HTTP(S)。公网服务应使用 HTTPS。
- QIAOAN_MODEL_TOKEN：可选 Bearer token。只保存在进程环境中，不写入 HTML，不提交至 Git。
- QIAOAN_MODEL_NAME：可选，页面和报告中显示的模型名称。
- QIAOAN_PORT：可选，本地端口，默认 8080。

配置完成后重启 server.py，页面“模型接入”检查配置。照片检测中选择“专业模型接口”。模型接口只在运行 server.py 的本地版本中启用，当前 Sites 静态托管版没有此 Python 后端。

## 上游请求

POST QIAOAN_MODEL_URL，Content-Type: application/json。

```json
{"image":"data:image/jpeg;base64,..."}
```

图片是工作副本，最长边不超过 1600 像素。若算法必须处理原始高清图，需要扩展上传及后端存储流程。

## 上游响应

```json
{
  "regions": [
    {"box": [0.12, 0.20, 0.38, 0.65], "label": "疑似裂缝", "score": 0.87}
  ]
}
```

box 为相对于输入图片宽高的归一化 x0,y0,x1,y1，左上角为原点；坐标范围 0–1，且右下大于左上。score 可省略；若存在必须在 0–1 之间。最多 200 个区域。无检测结果返回空数组，不得编造结果。

server.py 将 token 添加为 Authorization: Bearer，限制输入和响应大小，并验证区域坐标。默认仅监听本机，未配置时返回 503，失败时显示明确错误，不回退为虚构检测结果。该适配器不是多用户生产后端；线上正式接入需部署模型、认证、配额控制和持久存储。

## 已支持 / 未支持

已支持：图片级 JSON 请求、矩形区域和类别返回、可选模型分值、错误及超时处理。
未支持：SAM 掩膜显示、视频连续跟踪、点云融合、毫米级自动宽度量测、飞行设备控制。需要相应模型和设备服务后再扩展。
